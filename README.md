# 9만 에이커 웹 (Ninety Thousand Acres — fan-made web remake)

《9만 에이커》의 공개된 규칙·수치 분석 문서를 바탕으로, 브라우저에서 바로 돌아가게 다시 만든 영토 확장 + 턴제 오토배틀 SLG입니다.
바다 위에 떠 있는 디오라마 섬을 귀여운 로우폴리 3D로 그리고, 전투는 3D 전장에서 애니메이션으로 재생합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다(three.js는 cdnjs에서, 실패하면 jsDelivr에서 불러옵니다). 정적 서버로도 됩니다.

```
npx http-server . -p 8080
```

WebGL을 쓸 수 없는 기기에서는 자동으로 2D 픽셀 화면으로 바뀝니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조, 스타일(밝은 장난감 테마), SVG 아이콘 세트 |
| `js/data.js` | 24 병종 + 2 병기, 영웅 44종, 장비 25종 + 전용 장비, 몬스터 21종, 건물, 초상화 등급 확률표·천장, 계절 |
| `js/battle.js` | 격자 턴제 오토배틀 시뮬레이터 (이동·사거리·분노·스킬·상태이상·영웅·장비·확률 판정) |
| `js/world.js` | 40×40 타일맵, 경제, 건설·모집·훈련·제작 타이머, 행군, AI 세력(목표 지향 확장·행군 침공), PvP 시간창, 거점 내구, 승리 조건, 저장 |
| `js/models.js` | 귀여운 3D 모델 공장: 기본 도형을 정점색으로 구워 병사·몬스터·건물·나무를 만들고, 월드맵용 저폴리 버전도 만든다 |
| `js/world3d.js` | 3D 월드맵: 인스턴싱 타일·나무·몬스터, 계절색·낮밤·구름·눈/낙엽, 영토 경계선, 이름표, 카메라 |
| `js/battle3d.js` | 3D 전투 재생: 통통 뛰는 이동, 화살·돌 포물선, 피격 반짝임, 기절 별, 보호막, 쓰러짐, 승리 꽃가루, 자동 프레이밍 카메라 |
| `js/portrait.js` | 3D 모델을 작은 이미지로 구워 패널·팝업에 쓰는 초상화 생성기 |
| `js/render.js` | WebGL이 없을 때 쓰는 2D 픽셀 화면 |
| `js/ui.js` | HUD, 바텀시트 패널, 타일 팝업, 전투 화면, 터치·마우스·키보드 입력, 게임 루프 |
| `build-artifact.js` | 아티팩트 배포용 단일 페이지 변환 스크립트 |

## 조작

- 드래그로 이동, 휠·핀치로 확대, 두 손가락 비틀기·오른쪽 드래그·Q/E·화면 버튼으로 회전
- WASD/방향키 이동, 스페이스 일시정지, Esc 닫기
- 타일을 눌러 점령·공격 부대를 편성하고, 전투 예측으로 승률을 미리 볼 수 있다

## 핵심 규칙 (문서 기준)

- 1에이커에서 시작, 영토와 인접한 타일만 점령. 거점에서 멀수록 몬스터가 강함. 점령 후 1시간 보호.
- 식량은 생산량에서 전 병사 유지비를 뺀 순생산량만 입고. 모든 건물은 거점 레벨을 넘을 수 없음.
- 군영 5/10/15/20 → 병사 최대 레벨 3/4/5/6. 행군 창·방패·궁 62, 기병 74, 병기 46칸/시간.
- 전투는 턴제 자동. 공격·피격 시 분노 +1, 최대 분노 도달 시 다음 공격이 액티브 스킬. 병기·맥도·도끼기병은 분노 없음.
- 영웅은 같은 병종에 공봉하는 초상화(모디파이어). 등급 7급→…→1급→운명, 재그리기 확률표와 천장 적용. 영웅전당은 거점 Lv8.
- 장비는 대전마다 효과 8종이 무작위, 제작 시 수치 랜덤. 전용 장비는 대장간 10/18.
- 적 영지 공격은 20:00~24:00. 거점은 내구 3(수비전 3패 시 함락), 함락 시 그 세력의 영지가 넘어옴.
- 승리: 유적 Lv20 / Lv12 이상 유적 3개 / 모든 맹주 거점 함락 / 겨울 종료 후 점수 결산.

문서에 수치가 없던 병종·영웅은 추정치로 구현했으며 게임 안 도감에 "추정"으로 표시됩니다.
