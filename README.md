# 9만 에이커 웹 (Ninety Thousand Acres — fan-made web remake)

《9만 에이커》의 공개된 규칙·수치 분석 문서를 바탕으로, 브라우저에서 바로 돌아가게 다시 만든 영토 확장 + 턴제 오토배틀 SLG입니다.
300×300 = **9만 칸** 섬을 귀여운 로우폴리 3D 디오라마로 그리고(카메라 주변만 그려서 가볍게), 요새 안에서 건물을 배치·업그레이드하고 부대를 집결시키며, 전투는 3D 전장에서 애니메이션으로 재생합니다.
claude.ai 아티팩트로 게시하면 같은 섬을 여러 사람이 나눠 쓰는 **온라인 월드**도 됩니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다(three.js는 cdnjs에서, 실패하면 jsDelivr에서 불러옵니다). 정적 서버로도 됩니다.

```
npx http-server . -p 8080
```

WebGL을 쓸 수 없는 기기에서는 자동으로 2D 픽셀 화면으로 바뀝니다.

## 조작

- 드래그로 이동, 휠·핀치로 확대, 두 손가락 비틀기·오른쪽 드래그·Q/E·화면 버튼으로 회전
- WASD/방향키 이동, 스페이스 일시정지, Esc 닫기, **B** 요새 안/밖, **M** 전체 지도
- 타일을 눌러 부대째로 점령·공격하고, 전투 예측으로 승률을 미리 볼 수 있다
- 요새 안에서 건물을 눌러 올리거나 옮기고, 빈 터를 눌러 새 건물·망루·장식을 놓는다. 집결지에 편성한 부대가 모여 있다

## 온라인 월드 (아티팩트)

- 게시한 사람(편집자)이 첫 화면에서 월드를 만들고 속도(실시간 / 빠르게 / 아주 빠르게)를 고른다. 같은 링크로 들어온 사람은 "온라인 입장"으로 같은 9만 칸 섬에 거점을 받는다.
- 각자 자기 진행만 저장소에 쓴다: `players/<id>`(거점·영토·공개 수비군·주둔군·행군), `data/users/<id>/state`(비공개 진행), `inbox/<id>/items`(침공 보고), `chat`.
- 다른 영주의 땅은 20:00~24:00(게임 시각)에만 공격. 공격한 쪽이 시드와 양쪽 편성을 보내면, 수비한 쪽이 같은 시드로 똑같이 재생해 결과를 반영한다. 칸 주인이 겹치면 더 늦게 점령한 쪽이 이긴다.
- 거점이 세 번 뚫리면 땅을 모두 잃고 다른 곳에서 다시 시작(건물·병사는 유지). 접속하지 않은 동안에도 시간은 흐른다.
- 쓰기 권한: 개인 플랜에서는 공개 링크 없이 이메일로 편집자 초대한 사람, 조직 플랜에서는 참여(Contributor) 이상 권한의 구성원. 보기 전용은 구경만 할 수 있다.

## 핵심 규칙 (문서 기준)

- 300×300 섬, 1에이커에서 시작, 영토와 인접한 타일만 점령(전초 요새 3칸 안 포함). 섬 가운데로 갈수록 땅 레벨과 몬스터가 강하고, 한가운데에 대유적. 유적 25곳·거대 야수 16마리. 점령 후 1시간 보호.
- 식량은 생산량에서 전 병사 유지비를 뺀 순생산량만 입고. 모든 건물은 거점 레벨을 넘을 수 없음.
- 군영 5/10/15/20 → 병사 최대 레벨 3/4/5/6. 행군 창·방패·궁 62, 기병 74, 병기 46칸/시간.
- 전투는 턴제 자동. 공격·피격 시 분노 +1, 최대 분노 도달 시 다음 공격이 액티브 스킬. 병기·맥도·도끼기병은 분노 없음.
- 영웅은 같은 병종에 공봉하는 초상화(모디파이어). 등급 7급→…→1급→운명, 재그리기 확률표와 천장 적용. 영웅전당은 거점 Lv8.
- 장비는 대전마다 효과 8종이 무작위, 제작 시 수치 랜덤. 전용 장비는 대장간 10/18.
- 적 영지 공격은 20:00~24:00. 거점은 내구 3(수비전 3패 시 함락), 함락 시 그 세력의 영지가 넘어옴.
- 승리: 유적 Lv20 / Lv12 이상 유적 3개 / 모든 맹주 거점 함락 / 겨울 종료 후 점수 결산.

문서에 수치가 없던 병종·영웅은 추정치로 구현했으며 게임 안 도감에 "추정"으로 표시됩니다.
