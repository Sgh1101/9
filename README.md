# 9만 에이커 웹 (Ninety Thousand Acres — fan-made web remake)

《9만 에이커》의 공개된 규칙·수치 분석 문서를 바탕으로, 브라우저에서 바로 돌아가게 재구성한 영토 확장 + 턴제 오토배틀 SLG입니다.
외부 의존성 없이 순수 HTML / CSS / JavaScript(Canvas)로 작성되었습니다.

## 실행

`index.html`을 브라우저에서 열거나, 정적 서버로 서빙하면 됩니다.

```
npx http-server . -p 8080
```

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 레이아웃, 스타일, 시작 화면 |
| `js/data.js` | 24 병종 + 2 병기, 영웅 44종, 장비 25종 + 전용 장비, 몬스터 21종, 건물, 초상화 등급 확률표·천장, 계절 |
| `js/battle.js` | 격자 턴제 오토배틀 시뮬레이터 (이동거리·사거리·분노·스킬·상태이상·영웅·장비·확률 판정) |
| `js/world.js` | 44×44 타일맵, 식량/목재/석재 경제, 건설·모집·훈련·제작 타이머, 행군, AI 세력, PvP 시간창, 유적·최후 혈전·결산 승리, 저장 |
| `js/render.js` | 픽셀 스프라이트, 월드맵 렌더링, 전투 재생 |
| `js/ui.js` | 패널, 타일 팝업, 부대 편성·전투 예측, 전투 화면, 입력, 게임 루프 |
| `build-artifact.js` | 아티팩트 배포용 단일 페이지 변환 스크립트 |

## 핵심 규칙 (문서 기준)

- 1에이커에서 시작, 영토와 인접한 타일만 점령. 거점에서 멀수록 몬스터가 강함. 점령 후 1시간 보호.
- 식량은 생산량에서 전 병사 유지비를 뺀 순생산량만 입고. 모든 건물은 거점 레벨을 넘을 수 없음.
- 군영 5/10/15/20 → 병사 최대 레벨 3/4/5/6. 행군 창·방패·궁 62, 기병 74, 병기 46칸/시간.
- 전투는 턴제 자동. 공격·피격 시 분노 +1, 최대 분노 도달 시 다음 공격이 액티브 스킬. 병기·맥도·도끼기병은 분노 없음.
- 영웅은 같은 병종에 공봉하는 초상화(모디파이어). 등급 7급→…→1급→운명, 재그리기 확률표와 천장 적용.
- 장비는 대전마다 효과 8종이 무작위, 제작 시 수치 랜덤. 전용 장비는 대장간 10/18.
- 적 영지 공격은 20:00~24:00. 거점 함락 시 그 세력의 영지가 넘어옴.
- 승리: 유적 Lv20 / Lv12 이상 유적 3개 / 모든 맹주 거점 함락 / 겨울 종료 후 세력 점수 결산.

문서에 수치가 없던 병종·영웅은 추정치로 구현했으며 게임 안 도감에 "추정"으로 표시됩니다.
